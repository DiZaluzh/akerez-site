BERRY

A public site and visit experience for an independent beauty studio. This is custom work. It is not an AKEREZ product.

The project

AKEREZ designed the studio’s web presence around its services, its language, and the path toward a visit. The site is multilingual — French, English, Ukrainian, and Russian — because the studio’s clients are.

Scope

  • Public website
  • Service and visit experience
  • Client-facing tools around the studio
  • A visual system of the studio’s own, separate from AKEREZ

BERRY remains the studio’s name. It is shown here as selected work, not as software AKEREZ publishes.
